# doushouqi-ui - menu tablet

**Preview file:** `designs/previews/doushouqi-ui-menu-tablet.png`
**Spec SSOT:** `designs/specs/doushouqi-ui.md`

## Layout

Android tablet landscape viewport, approximately 16:10. Use 28dp outer padding. The left pane contains the near-square empty 7-by-9 bamboo board derived from the approved reference. A quiet family-standard 320dp right rail contains the circular package logo, title, version, and three vertically stacked actions.

## Modules

- Empty territory board: rounded tactile bamboo frame, precise dark grid, two textured deep-blue 2-by-3 rivers, six octagonal hunting-net trap emblems, and two `兽穴` labels.
- Package identity: circular-safe medallion showing two opposing animal silhouettes across a blue river.
- Title and version: exact Chinese text `斗兽棋` and `版本 0.0.3`.
- Actions: exact Chinese labels `单人模式`, `双人对战`, `退出游戏`.

## Visual details

Use `#EDF3EF` canvas, `#F7F8F3` rail, `#E5B85D` board, `#075D86` river, `#5A3A12` grid, `#0E5A3A` primary action, and `#C63A20` exit action. The memorable element is the tactile near-square bamboo board and high-contrast double-river canyon. The board carries material depth; the rail remains quiet and family-consistent.
