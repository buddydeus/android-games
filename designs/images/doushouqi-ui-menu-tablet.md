# doushouqi-ui - menu tablet

**Preview file:** `designs/previews/doushouqi-ui-menu-tablet.png`
**Spec SSOT:** `designs/specs/doushouqi-ui.md`

## Layout

Android tablet landscape viewport, approximately 16:10. Use 28dp outer padding. The left two-thirds contain a centered empty 7-by-9 Dou Shou Qi board. A quiet 320dp right rail contains the circular package logo, title, version, divider, and three vertically stacked actions.

## Modules

- Empty territory board: bamboo-gold grid, two deep mineral-blue 2-by-3 rivers, six marked traps, two dens, and subtle lion/tiger jump lines.
- Package identity: circular-safe medallion showing two opposing animal silhouettes across a blue river.
- Title and version: exact Chinese text `斗兽棋` and `版本 0.0.1`.
- Actions: exact Chinese labels `单人模式`, `双人对战`, `退出游戏`.

## Visual details

Use `#E7ECE8` canvas, `#F5F6F1` rail, `#D5B875` board, `#315F78` river, `#594A2F` grid, `#25664E` primary action, and `#A64332` exit text. The memorable element is the high-contrast double-river canyon. Use Android system-like CJK serif for the title and readable sans serif for actions. Flat tactile surfaces, very restrained shadows, no cards behind each line.
