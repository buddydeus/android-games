# 斗兽棋参考图还原模拟器验收

**日期：** 2026-07-27

**设备：** Android 36 `android_games_mvp_pad` 模拟器，2560×1800 物理分辨率

**应用版本：** 游戏中心 `0.0.5`，斗兽棋包 `0.0.3`

## 验收范围

- 游戏中心发现并打开包提供的 `斗兽棋` 名称与 Logo，外壳版本保持 `0.0.5`。
- 菜单真实加载包内 1400×1400 透明角竹木棋盘，显示 `版本 0.0.3`、`单人模式`、`双人对战`、`退出游戏`。
- 六个陷阱均显示双层八角捕兽网纹章、八条向心网线、四个内倒钩、中央锁结和浅赭印底，不再使用含义不明确的交叉线。
- 单人对局真实加载松绿/朱砂双方 16 张透明浮雕棋子，兽名、河道、陷阱和兽穴清晰可辨。
- 完成一轮玩家走子与后台机器人应答，确认棋子移动、回合恢复及最新移动四角标记。
- 右栏继续使用游戏家族统一的 300dp 对局栏、320dp 菜单栏、比分、回合、悔棋与返回菜单形式。
- 自动测试校验棋盘和棋子的 PNG 类型、精确尺寸、透明角、完整资源集合，以及 bounds-first 解码与单资源回退。
